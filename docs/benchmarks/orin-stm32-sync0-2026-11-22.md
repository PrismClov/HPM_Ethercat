# Orin SOEM 单 STM32 从站 DC 测量

2026-11-22，在 Jetson Orin 的原生 Linux 5.15.148-tegra 上通过 enP8p1s0 运行 SOEM。总线上仅识别到 evb9252_dig（0x1337/0x04d2）。线程固定 CPU 4，SCHED_FIFO 优先级 45。输出 2 字节保持为零，输入 1 字节，期望 WKC 为 3。

PRE-OP 配置 SYNC0，回读 ESC 0x0981 为 3，0x09A0 与各档周期一致。SAFE-OP 开始循环交换，再请求 OP。STM32 对 0x1C32:01 的查询未返回有效数据，应用中断的触发源未独立验证。

以下为 10 秒扫频及独立 120 秒复测的原始输出。host 为 Orin 单调时钟记录的连续有效收帧间隔相对目标周期的绝对误差，dc_interval 为同一对帧的 SOEM 参考时钟时间戳间隔绝对误差，rtt 为主机收发耗时。间隔统计排除跨漏发时隙、跨无效帧的样本；missed 与 late 分别统计漏发和跨截止时间完成。单站自身为 DC 参考时钟。SYNC0 引脚的物理边沿需外部仪器测量。
