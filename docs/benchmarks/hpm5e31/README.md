## 2026-11-19 实机记录

单台 HPM5E31-KIT，FreeRun，RxPDO 固定为零。两种后端均进入 OP。静态 GPIO 为 `0x0000`，与 CoE 单独读取 `0x6000:00` 一致。有效 PDI 相位为 0–1 µs。IgH 通过 WSL2 的 TAP/Npcap 转发链路测试，另用 SOEM 在同一转发链路测试作为对照。Windows 的 SOEM 数据来自专用网卡直连。[实机扫频与复测 CSV](hpm-pdo-live-2026-11-19.csv)
Windows SOEM 直连的 2 kHz 复测持续 30 秒，P50/P99 为 499/631 µs，PDO 无效率 0.00167%，漏调度 0.32333%。提高到 4 kHz 后，15 秒测得漏调度 1.46333%。IgH 转发的 400 Hz 复测持续 25 秒，P50/P99 为 2499/2626 µs，PDO 无效率 0.18%。同一路径下 IgH 在 1 kHz 和 2 kHz 的 PDO 无效率分别为 1.18414%（25 秒）和 4.25500%（10 秒）。

另用 Windows PySOEM 在单进程里绕开 Rust 和后端的管道，5 秒短测峰值约 7.9k 个有效 PDO/s，同时漏掉约 60% 的 20 kHz 目标时隙。这是吞吐探测，实机数据对应单板、固定零值输出、非 DC 的主站收发路径。[单进程探测 CSV](hpm-pdo-direct-probe-2026-11-19.csv)

## 2026-11-19 Orin 原生 SOEM 基线

Orin 的原生 Linux 5.15.148-tegra 和现有 SOEM 2.0.0 静态库，使用物理网口 `enP8p1s0` 经交换机连接单台 HPM5E31-KIT。原固件以 FreeRun 运行，输出 PDO 固定为零。GPIO 为 `0x0002`，PDI 相位为 1 µs。每个独立复测频点重新进入 OP，避免跨频点打印和排序造成的发帧空窗。详情见 [Orin 原生 SOEM 基线 CSV](soem-orin-baseline-2026-11-19.csv)。

## 2026-11-19 Orin 原生 SOEM 回读

通过 Orin USB 上的 CMSIS-DAP 加载 RAM 固件。Orin 自带的 OpenOCD 0.11 未识别探针的两字节能力字段，使用独立的 ARM64 OpenOCD 0.12 连接后完成加载。EtherCAT 收发仍由 Orin 的 SOEM 和物理网口完成。

| 目标频率 | 独立复测 | 回读延迟 P50 / P99 / 最大 | 周期偏差 P99 | 未回显 | 漏调度 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 8 kHz | 30 s | 174.97 / 183.03 / 1350.90 µs | 14.73 µs | 0/239686 | 0.131% |
| 10 kHz | 30 s | 149.91 / 250.93 / 1978.47 µs | 90.26 µs | 0/296309 | 1.230% |

两个频点都保持 OP，已发起周期中无无效 PDO。以漏调度低于 0.5%、PDO 与回读均无丢失作为本次验收口径，8 kHz 是 30 秒复测通过的最高频点。完整数据见 [Orin 原生 SOEM 回读 CSV](soem-orin-echo-2026-11-19.csv)。
